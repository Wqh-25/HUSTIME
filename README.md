# HUSTIME

HUSTIME = HUST + TIME，共用字母T。项目面向大学生，将已授权QQ群通知整理为个人待办和日程。

首版设计包含QQ官方消息接入、大模型结构化提取、无模型时的有限规则提取、候选确认、个人日历、改期与取消追踪，以及站内提醒。不包含小组任务分工、依赖调度或团队绩效管理。
